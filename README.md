# Cyber Arcade 🎮

آرکید مستقل و رایگان برای مرورگر، بدون ثبت‌نام.

## بازی‌های فعلی
- آخرین پایگاه: ماجراجویی با نمای شبه‌سه‌بعدی
- خیابان نئون: رانندگی آرکید
- منطقه خطر: تمرین تیراندازی

## انتشار با GitHub Pages
در Settings → Pages، گزینه Deploy from a branch را انتخاب کن، Branch را روی main و پوشه را روی /(root) بگذار و Save کن.

آدرس سایت: https://s09560726-hash.github.io/cyber-arcade/

## کنترل‌ها
- ماجراجویی: جهت‌ها یا WASD
- رانندگی: چپ و راست
- تیراندازی: کلیک/لمس هدف یا دکمه شلیک

برای اولین بارگذاری اینترنت لازم است. پس از بارگذاری، Service Worker صفحه را cache می‌کند و می‌توان آفلاین بودن را آزمایش کرد.

## نکته
این‌ها بازی‌های مستقل آزمایشی ساخته‌شده برای پروژه‌اند و نسخه یا پورت بازی‌های تجاری PS5 نیستند. گرافیک فعلی دوبعدی با افکت پرسپکتیو است، نه گرافیک سه‌بعدی واقعی.
