# Cyber Arcade 🎮

آرکید رایگان و سبک برای مرورگر، بدون ثبت‌نام و بدون دانلود بازی‌های تجاری.

## بازی‌ها
- مار
- پینگ‌پنگ
- آجرشکن

## انتشار با GitHub Pages
1. وارد **Settings → Pages** شو.
2. در **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کن.
3. Branch را روی **main** و پوشه را روی **/(root)** بگذار و **Save** را بزن.
4. پس از انتشار، آدرس زیر را باز کن:

https://s09560726-hash.github.io/cyber-arcade/

## استفاده آفلاین
برای بار اول اینترنت لازم است. Service Worker بعد از بارگذاری موفق، صفحه را cache می‌کند. سپس با قطع اینترنت و بازکردن دوبارهٔ صفحه، آفلاین بودن را آزمایش کن.

## کنترل‌ها
- صفحه‌کلید: کلیدهای جهت‌نما
- موبایل: دکمه‌های روی صفحه و حرکت لمسی
- دسته: در صورت پشتیبانی مرورگر از Gamepad API

## محدودیت‌ها
این پروژه شامل سه بازی کوچک HTML5 است. بازی‌های تجاری PS5/PC را میزبانی یا استریم نمی‌کند و سازگاری کامل مرورگر داخلی PS5 تضمین‌شده نیست.
